Privacy Policy

Vintage Beats Live Automation

Last updated: September 29, 2026

Overview

Vintage Beats Live Automation is a private application operated by Orvalia Studio for managing the Vintage Beats Brasil YouTube channel.

The application is used only by the application owner and authorized administrator. It is not offered as a public service.

Google and YouTube data

The application uses Google OAuth 2.0 and the YouTube Data API to access and manage YouTube resources explicitly authorized by the account owner.

The application may access information necessary to:

  • View YouTube channel information.
  • View live broadcasts and live streams.
  • Create and manage YouTube Live broadcasts.
  • Connect broadcasts to existing live streams.
  • Start and end live broadcasts.
  • Update titles, descriptions, thumbnails and other broadcast metadata.
  • Manage archived live sessions and replay content.

How data is used

Google user data is used exclusively to provide the YouTube Live automation functionality described on this website.

The application does not sell, rent, share or distribute Google user data to third parties and does not use Google user data for advertising, profiling or unrelated marketing.

Data storage and security

OAuth credentials and authorization tokens may be stored on systems controlled by the application owner solely for authentication with Google and YouTube services.

Access to these credentials is restricted to the application owner and systems required to operate the automation.

Data retention and deletion

Authentication data is retained only for as long as required to operate the application. The application owner may revoke Google account access at any time through Google Account security settings and may delete locally stored authorization credentials from the systems running the application.

Google API Services User Data Policy

Vintage Beats Live Automation's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Third-party services

Vintage Beats Live Automation uses Google OAuth 2.0, Google APIs and the YouTube Data API. Use of those services is also subject to Google's applicable terms and policies.
